# 👻 Ghost सुरक्षा मॉड्यूल
**PowerShell आधारित Windows आरू Azure सुरक्षा मजबूती औजार**

> **Windows अंतिम बिंदु आरू Azure माहौल लेली सक्रिय सुरक्षा मजबूती।** Ghost अनावश्यक सेवा आरू प्रोटोकॉल कें बंद करकें आम हमला वेक्टर कें कम करै मं॑ मदद करै वाला PowerShell आधारित मजबूती फंक्शन दै छै।

## ⚠️ महत्वपूर्ण जिम्मेदारी अस्वीकरण

**परीक्षण जरूरी छै**: Ghost कें हमेशा पहिलें गैर-उत्पादन माहौल मं॑ टेस्ट करऽ। सेवा बंद करलें वैध व्यापारिक काम कें प्रभावित करी सकै छै।

**कोनो गारंटी नै छै**: भलें Ghost आम हमला वेक्टर कें निशाना बनावै छै, कोनो सुरक्षा औजार सब्भे हमला कें रोकी नै सकै छै। ई एगो व्यापक सुरक्षा रणनीति केरऽ एगो घटक छै।

**परिचालन प्रभाव**: कुछ फंक्शन सिस्टम कार्यक्षमता कें प्रभावित करी सकै छै। तैनाती सें पहिलें हर सेटिंग कें ध्यान सें देखऽ।

**पेशेवर मूल्यांकन**: उत्पादन माहौल लेली, सुरक्षा विशेषज्ञ सें सलाह लऽ जेकरा सें ई सुनिश्चित होय सकै कि सेटिंग्स रउरा संगठन केरऽ जरूरत सें मेल खाय छै।

## 📊 सुरक्षा लैंडस्केप

Ransomware नुकसान **2025 मं॑ $57 बिलियन** तलक पहुँच गेलै, अनुसंधान दिखावै छै कि बहुत सफल हमला बुनियादी Windows सेवा आरू गलत कॉन्फ़िगरेशन केरऽ फायदा उठावै छै। आम हमला वेक्टर मं॑ शामिल छै:

- **90% ransomware घटना** मं॑ RDP दुरुपयोग शामिल छै
- **SMBv1 कमजोरी** WannaCry आरू NotPetya जैसनऽ हमला कें सक्षम बनेलकै
- **दस्तावेज मैक्रो** प्राथमिक मैलवेयर डिलीवरी तरीका बनलऽ रहै छै
- **USB आधारित हमला** एयर-गैप्ड नेटवर्क कें लक्षित करतऽ रहै छै
- **PowerShell दुरुपयोग** हाल केरऽ साल मं॑ बहुत बढ़लै छै

## 🛡️ Ghost सुरक्षा फंक्शन

Ghost **16 Windows मजबूती फंक्शन** प्लस **Azure सुरक्षा एकीकरण** दै छै:

### Windows एंडपॉइंट मजबूती

| फंक्शन | उद्देश्य | विचार |
|----------|---------|----------------|
| `Set-RDP` | Remote Desktop पहुँच केरऽ प्रबंधन करै छै | दूरस्थ प्रशासन कें प्रभावित करी सकै छै |
| `Set-SMBv1` | पुरनऽ SMB प्रोटोकॉल कें नियंत्रण करै छै | बहुत पुरनऽ सिस्टम लेली जरूरी |
| `Set-AutoRun` | AutoPlay/AutoRun कें नियंत्रण करै छै | उपयोगकर्ता सुविधा कें प्रभावित करी सकै छै |
| `Set-USBStorage` | USB स्टोरेज डिवाइस कें सीमित करै छै | वैध USB इस्तेमाल कें प्रभावित करी सकै छै |
| `Set-Macros` | Office मैक्रो निष्पादन कें नियंत्रण करै छै | मैक्रो-सक्षम दस्तावेज कें प्रभावित करी सकै छै |
| `Set-PSRemoting` | PowerShell रिमोटिंग केरऽ प्रबंधन करै छै | दूरस्थ प्रबंधन कें प्रभावित करी सकै छै |
| `Set-WinRM` | Windows Remote Management कें नियंत्रण करै छै | दूरस्थ प्रशासन कें प्रभावित करी सकै छै |
| `Set-LLMNR` | नाम रिज़ॉल्यूशन प्रोटोकॉल केरऽ प्रबंधन करै छै | आम तौर पर अक्षम करनाय सुरक्षित छै |
| `Set-NetBIOS` | TCP/IP पर NetBIOS कें नियंत्रण करै छै | पुरनऽ एप्लिकेशन कें प्रभावित करी सकै छै |
| `Set-AdminShares` | प्रशासनिक शेयर केरऽ प्रबंधन करै छै | दूरस्थ फ़ाइल पहुँच कें प्रभावित करी सकै छै |
| `Set-Telemetry` | डेटा संग्रह कें नियंत्रण करै छै | निदान क्षमता कें प्रभावित करी सकै छै |
| `Set-GuestAccount` | गेस्ट खाता केरऽ प्रबंधन करै छै | आम तौर पर अक्षम करनाय सुरक्षित छै |
| `Set-ICMP` | ping प्रतिक्रिया कें नियंत्रण करै छै | नेटवर्क निदान कें प्रभावित करी सकै छै |
| `Set-RemoteAssistance` | Remote Assistance केरऽ प्रबंधन करै छै | helpdesk संचालन कें प्रभावित करी सकै छै |
| `Set-NetworkDiscovery` | नेटवर्क खोज कें नियंत्रण करै छै | नेटवर्क ब्राउज़िंग कें प्रभावित करी सकै छै |
| `Set-Firewall` | Windows Firewall केरऽ प्रबंधन करै छै | नेटवर्क सुरक्षा लेली महत्वपूर्ण |

### Azure क्लाउड सुरक्षा

| फंक्शन | उद्देश्य | आवश्यकता |
|----------|---------|--------------|
| `Set-AzureSecurityDefaults` | बुनियादी Azure AD सुरक्षा कें सक्षम करै छै | Microsoft Graph अनुमति |
| `Set-AzureConditionalAccess` | पहुँच नीति कें कॉन्फ़िगर करै छै | Azure AD P1/P2 लाइसेंसिंग |
| `Set-AzurePrivilegedUsers` | विशेषाधिकार खाता केरऽ ऑडिट करै छै | Global Admin अनुमति |

### एंटरप्राइज़ तैनाती विकल्प

## 🔍 फंक्शन विवरण

### मुख्य मजबूती फंक्शन

#### नेटवर्क सेवा
- **RDP**: रिमोट डेस्कटॉप पहुँच कें ब्लॉक करै छै या पोर्ट कें रैंडमाइज़ करै छै
- **SMBv1**: पुरनऽ फ़ाइल शेयरिंग प्रोटोकॉल कें निष्क्रिय करै छै
- **ICMP**: जासूसी लेली ping प्रतिक्रिया कें रोकै छै
- **LLMNR/NetBIOS**: पुरनऽ नाम रिज़ॉल्यूशन प्रोटोकॉल कें ब्लॉक करै छै

#### एप्लिकेशन सुरक्षा
- **मैक्रो**: Office एप्लिकेशन मं॑ मैक्रो निष्पादन कें निष्क्रिय करै छै
- **AutoRun**: हटाय जाय वाला मीडिया सें स्वचालित निष्पादन कें रोकै छै

#### दूरस्थ प्रबंधन
- **PSRemoting**: PowerShell दूरस्थ सत्र कें निष्क्रिय करै छै
- **WinRM**: Windows Remote Management कें बंद करै छै
- **Remote Assistance**: दूरस्थ सहायता कनेक्शन कें ब्लॉक करै छै

#### पहुँच नियंत्रण
- **Admin Shares**: C$, ADMIN$ शेयर कें निष्क्रिय करै छै
- **Guest Account**: गेस्ट खाता पहुँच कें निष्क्रिय करै छै
- **USB Storage**: USB डिवाइस उपयोग कें सीमित करै छै

### Azure एकीकरण
```powershell
# Azure टेनेंट सें जुड़ऽ
Connect-AzureGhost -Interactive

    RDP = $true

```

## ⚠️ महत्वपूर्ण विचार

### परीक्षण आवश्यकता
- **लैब माहौल**: पहिलें अलग माहौल मं॑ सब्भे सेटिंग केरऽ टेस्ट करऽ
- **चरणबद्ध तैनाती**: समस्या पहचानै लेली धीरे-धीरे फैलाऽ
- **रोलबैक योजना**: सुनिश्चित करऽ कि जरूरत पड़लें पर बदलाव कें वापस करी सकै छियै
- **दस्तावेज़ीकरण**: रिकॉर्ड करऽ कि रउरा माहौल लेली कोन सेटिंग काम करै छै

### संभावित प्रभाव
- **उपयोगकर्ता उत्पादकता**: कुछ सेटिंग दैनिक वर्कफ़्लो कें प्रभावित करी सकै छै
- **पुरनऽ एप्लिकेशन**: पुरनऽ सिस्टम कें कुछ विशिष्ट प्रोटोकॉल केरऽ जरूरत होय सकै छै
- **दूरस्थ पहुँच**: वैध दूरस्थ प्रशासन पर प्रभाव केरऽ विचार करऽ
- **व्यापारिक प्रक्रिया**: सत्यापित करऽ कि सेटिंग महत्वपूर्ण फंक्शन कें नुकसान नै पहुँचावै

### सुरक्षा सीमा
- **गहिरऽ रक्षा**: Ghost सुरक्षा केरऽ एगो परत छै, पूरा समाधान नै छै
- **चालू प्रबंधन**: सुरक्षा कें निरंतर निगरानी आरू अपडेट केरऽ जरूरत होय छै
- **उपयोगकर्ता प्रशिक्षण**: तकनीकी नियंत्रण कें सुरक्षा जागरूकता सें जोड़लऽ जानाय चाही
- **खतरा विकास**: नया हमला तरीका मौजूदा सुरक्षा कें बायपास करी सकै छै

## 🎯 हमला परिदृश्य उदाहरण

भलें Ghost आम हमला वेक्टर कें लक्षित करै छै, विशिष्ट रोकथाम उचित कार्यान्वयन आरू परीक्षण पर निर्भर करै छै:

### WannaCry-शैली हमला
- **न्यूनीकरण**: `Set-Ghost -SMBv1` कमजोर प्रोटोकॉल कें निष्क्रिय करै छै
- **विचार**: सुनिश्चित करऽ कि कोनो पुरनऽ सिस्टम SMBv1 केरऽ जरूरत नै छै

### RDP-आधारित Ransomware
- **न्यूनीकरण**: `Set-Ghost -RDP` रिमोट डेस्कटॉप पहुँच कें ब्लॉक करै छै
- **विचार**: वैकल्पिक दूरस्थ पहुँच तरीका केरऽ जरूरत होय सकै छै

### दस्तावेज़-आधारित मैलवेयर
- **न्यूनीकरण**: `Set-Ghost -Macros` मैक्रो निष्पादन कें निष्क्रिय करै छै
- **विचार**: वैध मैक्रो-सक्षम दस्तावेज़ कें प्रभावित करी सकै छै

### USB-वितरित खतरा
- **न्यूनीकरण**: `Set-Ghost -USBStorage -AutoRun` USB कार्यक्षमता कें सीमित करै छै
- **विचार**: वैध USB डिवाइस उपयोग कें प्रभावित करी सकै छै

## 📚 सर्वोत्तम अभ्यास

### तैनाती सें पहिलें
1. **वर्तमान स्थिति दस्तावेज़**: बदलाव सें पहिलें `Get-Ghost` चलाऽ
2. **पूरी तरह परीक्षा**: गैर-उत्पादन माहौल मं॑ मान्य करऽ
3. **रोलबैक योजना**: हर सेटिंग कें कैसें वापस करै केरऽ जानऽ
4. **हितधारक समीक्षा**: सुनिश्चित करऽ कि व्यापारिक इकाई बदलाव केरऽ अनुमोदन करै छै

### तैनाती केरऽ दौरान
1. **चरणबद्ध दृष्टिकोण**: पहिलें पायलट समूह मं॑ तैनात करऽ
2. **प्रभाव निगरानी**: उपयोगकर्ता शिकायत या सिस्टम समस्या देखऽ
3. **समस्या दस्तावेज़**: भविष्य केरऽ संदर्भ लेली कोनो समस्या रिकॉर्ड करऽ
4. **बदलाव संचार**: उपयोगकर्ता कें सुरक्षा सुधार केरऽ बारे मं॑ बताऽ

### तैनाती केरऽ बाद
1. **नियमित मूल्यांकन**: सेटिंग सत्यापित करै लेली समय-समय पर `Get-Ghost` चलाऽ
2. **दस्तावेज़ीकरण अपडेट**: सुरक्षा कॉन्फ़िगरेशन कें वर्तमान रखऽ
3. **प्रभावशीलता समीक्षा**: सुरक्षा घटना केरऽ निगरानी करऽ
4. **निरंतर सुधार**: खतरा परिदृश्य केरऽ आधार पर सेटिंग समायोजित करऽ
